================================
XChem-CAR Documentation
================================

XChem-CAR (Chemist Assisted Robotics) is an open-source platform for
automated chemistry protocol generation on the OpenTrons liquid-handling
robot.  It takes target molecules, plans retrosynthetic routes, and
generates ready-to-run OT-2 Python scripts along with starting-material
ordering sheets and interactive session visualisations.
